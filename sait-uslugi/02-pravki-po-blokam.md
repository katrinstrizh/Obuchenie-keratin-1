# Правки по блокам сайта услуг

Нумерация — как в текущем коде (БЛОК 0 … БЛОК 19). Каждый блок — это HTML-блок Tilda (T123).
Правило: **сначала Claude в беседе пишет новый код блока целиком**, показывает Кате, после «да» Claude в Chrome заменяет код в Tilda.
Где нужны данные Кати — ссылка на вопрос из `00-voprosy-k-kate.md` (В1, В2…).
