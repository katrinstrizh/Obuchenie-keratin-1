# Настройки Tilda: страница услуг и сайт

Всё ниже вписывается не в блоки страницы, а в **настройки**. Названия разделов Tilda могут немного отличаться — ориентироваться по смыслу.
`{URL}` = адрес страницы из вопроса 1 в `00-voprosy-k-kate.md`.

---

```html

    .section-white::before, .section-light::before, .hero::before { background-attachment: scroll !important; }

  }
  /* Надпись «листайте» нужна только там, где карточки не помещаются */
  @media (min-width: 1200px) { .slider-note { display: none; } }
</style>
```

## Б. Настройки всего сайта (Сайт → Настройки)

| Раздел | Что сделать |
|---|---|
| Аналитика → Яндекс Метрика | Подключить счётчик (номер — вопрос 13). Включить Вебвизор |
| Аналитика → цели | Цели Метрики: `click_max` (клики по Max), `click_tel` (звонки), `click_photo` (кнопка «Узнать цену по фото»), `click_yclients` (онлайн-запись). Код целей — в файле 02, раздел «Общее» |
| Иконка сайта (favicon) | Квадрат 512×512: буквы «KE» белым на изумрудном градиенте |
| Домен | Проверить, что страница открывается по https и с www и без www ведёт на один адрес |
| Ещё → 404 | Своя страница 404 с кнопкой «На главную» и «Узнать цену по фото» (в плане есть «404 услуг» на kupit-keratin.ru) |
| SEO-помощник Tilda | Открыть, исправить все красные пункты, прислать Кате список жёлтых |
| Яндекс Вебмастер | Сайт добавлен и подтверждён; после правок — «Переобход страниц» для `{URL}` |
| Карта сайта (sitemap) | Страница услуг в ней есть |

## В. Проверка после сохранения

1. Опубликовать (только после «да» от Кати).
2. Открыть страницу в режиме инкогнито с телефона (или окно 390 px в Chrome).
3. Проверить разметку: https://validator.schema.org/ — вставить `{URL}`, ошибок быть не должно.
4. Переслать ссылку себе в Max/Telegram — проверить картинку и заголовок превью.
5. Записать результат в раздел «Журнал» файла `03-zadaniya-claude-v-chrome.md`.
