# Задания для Claude в Chrome — сайт услуг

Расширение работает в Chrome Кати, где она уже вошла в Tilda, Яндекс Бизнес, Метрику.

## Правила (обязательно)

1. **Ничего не публиковать без «да» от Кати.** В Tilda: сохранять черновик → показать скриншот → публиковать только после подтверждения.
2. **Перед заменой кода блока** скопировать старый код в файл `sait-uslugi/backup/blok-NN-YYYY-MM-DD.html` (или отдать Кате текстом), чтобы можно было вернуть.
3. Не удалять страницы, проекты, не менять домен, тариф, оплату, пароли.
4. Не заполнять данные, которых нет в `00-voprosy-k-kate.md` (ИНН, рейтинг, ссылки) — отмечать «⏳ ждёт ответа».
5. Работать в новой вкладке, не трогать открытые вкладки Кати.
6. Если Tilda просит войти, капча, двухфакторка — остановиться и попросить Катю.
7. После каждого задания — запись в «Журнал» внизу и статус в `02-pravki-po-blokam.md`.

## Задание 0. Разведка (только смотреть) ⬜
1. Открыть tilda.cc → Мои сайты. Найти проект со страницей услуг (адрес — В1). Если не найден — список проектов и страниц прислать Кате.
2. Открыть страницу услуг в редакторе. Записать: сколько блоков, их тип (T123 и др.), порядок, совпадает ли с блоками 0–19 из `02`.
3. Открыть опубликованную страницу на ширине 390 px и 1440 px, сделать по 3 скриншота (верх, середина, низ).
4. Проверить ссылки в меню и в плашках hero: `#keratin #botox #wowboost #reconstruction #expert #reviews #faq #contacts` — какие не работают.
5. Открыть Настройки страницы и записать текущие заголовок, описание, SEO-поля, код в HEAD.
6. Отчёт Кате: что увидел, что сломано, что не совпадает с файлами.

## Задание 1. Срочные правки ⬜
1. Блок 19 (футер): удалить строку с `ИНН: 1234567890` (или вставить реальные данные, если В2 заполнен).
2. Блок 18 (SEO-облако): удалить блок.
3. Блок 17: обернуть каждое фото сертификатов и обучений в ссылку на само фото (`<a href="URL_фото" target="_blank">`), оставить одну подсказку «Нажмите на фото, чтобы увеличить».
4. Найти и заменить формулировки из таблицы «Запрещённые формулировки» (`02`, раздел «Общее»).
5. Скриншоты → Катя → публикация.

## Задание 2. Настройки страницы и сайта ⬜
Выполнить файл `01-tilda-nastroyki-stranicy.md`, разделы А1–А5 и Б по порядку. Поля с `{…}` без ответа — пропустить.
Проверка — раздел В того же файла.

## Задание 3. Замена блоков новым кодом ⬜
Для каждого блока, у которого в `02` статус «код готов»:
1. Сделать бэкап старого кода (правило 2).
2. Открыть блок → «Контент» → заменить HTML целиком на код из `sait-uslugi/kod/blok-NN.html`.
3. Сохранить, проверить на 390 px и 1440 px.
4. Статус в `02` → ✅ после публикации.
Код блоков пишет обычная беседа Claude и кладёт в папку `sait-uslugi/kod/`.

## Задание 4. Порядок блоков ⬜
Перетащить блоки в порядок из `02` («Новый порядок блоков»). Скриншот → Катя → публикация.

## Задание 5. Яндекс Бизнес ⬜ (вне Tilda, см. `04-vne-saita.md`)
1. Открыть business.yandex.ru → карточка «Keratin.Expert».
2. Сверить: адрес с «вход через Озон», телефон, сайт = страница услуг, часы.
3. Прайс: внести все услуги с вилками из `00` (раздел «Что уже известно»).
4. Фото: загрузить фото «до/после», которые Катя выберет (не загружать без её выбора).
5. Взять код виджета отзывов → положить в `sait-uslugi/kod/vidzhet-otzyvy.html` для блока 10.
6. Ответы на неотвеченные отзывы — **написать черновики**, показать Кате, публиковать только после «да».

## Задание 6. Метрика ⬜ (⏳ В13)
1. metrika.yandex.ru → счётчик сайта → Цели: создать JavaScript-события `click_max`, `click_tel`, `click_tg`, `click_yclients`, `click_photo`.
2. Вставить код целей из `02` («Общее») в HEAD сайта.
3. Нажать кнопки на опубликованной странице и проверить, что цели засчитываются (через 5–10 минут).

## Задание 7. Финальная проверка ⬜
- Телефон 390 px: шапка в одну строку, шрифты ≥13 px, все кнопки нажимаются, якоря ведут куда надо, фото увеличиваются, FAQ раскрывается.
- PageSpeed Insights (pagespeed.web.dev) для страницы — записать оценку мобильной версии до и после.
- validator.schema.org — без ошибок.
- Превью ссылки в Max/Telegram.
- Отчёт Кате: что сделано, что ждёт её ответов.
